# Graph-first relabelling of the full first-pair domain

This is a symmetry reduction, not an extremal theorem or an exclusion.
It keeps the native parent domain and every ordered initial pair.

First apply one certified relabelling per retained P1 graph. It preserves
H,A,B,C,D, the mandatory frame intersection, and every individual native
preimage field; it transports the whole G=P1 union K_C union K_D and
each exact allowed kernel list. Its target is another retained graph in
the same native domain. A minimal representative is convenient but is
not a proof premise: any such certified target suffices.

Next fix every vertex incident to the target P1 graph. Permute only its
isolated vertices within each control cell, sorting their two membership
bits in the ordered pair of initial images. This fixes P1, all entrance
sets and all fields; it therefore also fixes G and every compatible
kernel domain. Compose the two relabellings. Every actual initial pair
is transported to one saved representative with its whole letter domain.
Counts cover every labelled ordered pair; the transport may deliberately
retain nonminimal orbit representatives.

The independent audit rebuilds the complete native graph list and frame
families. It validates the supplied first permutation literally, then
constructs the second permutation independently, tests every transported
kernel and all field sets, and recomputes the complete representative
multiplicities. It does not assume the compiler's canonical choice.
Only a subsequent full flag-tree audit could exclude the geometry.
