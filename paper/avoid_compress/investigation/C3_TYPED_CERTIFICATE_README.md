# Disjoint c3 typed-entrance certificate

This auxiliary package contains a symbolic four-type third-entrance
reduction at (13,9,1) for arbitrary finite alphabets and symbolic binary
exclusions of D={0,6} and D={0,1,6}. Binary c3 retains D={6} or D={2,6};
unrestricted c3 retains four types. The entire c3 joint orbit is not
excluded. Both extrema remain [11,12]; no numerical alphabet separation
is proved. This package is outside the unchanged 109-file paper supplement.

Read C3_TYPED_THIRD_ENTRANCES.md, C3_D9_BINARY_EXCLUSION.md,
C3_D4_PROFILE_I_EXCLUSION.md and C3_D4_BINARY_EXCLUSION.md. The proofs
use disjoint input preimages, exact equality-flag annihilator dimensions
and strong connectivity from a safe nine-set. No native row scan, solver
answer or timeout is used as an exclusion. The singleton antecedent
note is included for its five-pair endpoint upper argument; historical
native scans mentioned there are not used or reproduced in this package.

Python 3.10+ and its standard library suffice. Run:

```sh
python check_c3_typed_third.py
```

It must report status pass, four typed D orbits and 35 labelled D sets,
196 D9 coordinate profiles with 14 admitted, 3,584 D4 rank-six checks,
420 D4 singleton coordinate profiles, binary D9 and D4 exclusions, and
two/four remaining binary/unrestricted c3 third profiles. The complete
checks include all 4,140 abstract R kernels, exact rational ranks, all
literal nine-sets and both second-image core-trap arguments. Joint orbit
counts remain 30/43. The supplied c3_geometric_third_controls.json contains
only the twelve directly used c3 entries from the earlier geometric
inventory, with their historical source digest. The larger source file
and other cases are omitted. The checker recomputes all labelled geometry
and applies actual-row types independently; no original frontier is needed.

CHECKSUMS.txt authenticates the distributed bytes. The independent audit
can be regenerated byte for byte without any full-frontier data, native
compiler, external package, numerical rank tolerance or network access.
