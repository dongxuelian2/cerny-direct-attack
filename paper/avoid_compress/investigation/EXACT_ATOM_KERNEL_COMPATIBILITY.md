# Exact rank-n-1 kernels in a membership-atom field

Let (I_i) and (O_i) be indexed partitions of a finite nonempty Q,
allowing empty atoms. A field requires f(I_i) contained in O_i.
A permutation realizes the field exactly when |I_i|=|O_i| for
every i. For a specified unordered pair e, a rank-|Q|-1 map with
that sole kernel pair realizes it exactly when:

* both endpoints of e belong to one input atom I_j;
* |I_i|-1_(i=j) <= |O_i| for every i.

Necessity follows from the disjoint output atoms and injectivity on
the quotient identifying e. Sufficiency follows by injecting each
input-atom quotient into its corresponding output atom independently.
These injections have disjoint images; the sole repeated fiber is e.
The statement applies to arbitrary atom counts, overlaps in the sets
defining memberships, and empty atoms. It asserts exact letter
realizability only, never realizability of an automaton or equality.

For a nonempty guard set K and protected set J, a realizable
permutation or specified-kernel letter can satisfy f(K) not contained
in J exactly when some output atom corresponding to a K endpoint
has an element outside J. If no such element exists, every K image
is protected. Conversely choose one guard quotient block's image
outside J, and complete the remaining injections in each atom.
The atom capacity conditions ensure completion after this choice.
If both guards belong to e, they represent the same quotient block.
