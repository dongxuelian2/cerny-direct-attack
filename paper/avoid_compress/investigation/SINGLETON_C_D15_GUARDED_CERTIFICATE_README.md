# Two-root unrestricted D15 guarded fourth certificate

This auxiliary package excludes E16 and E126 in B0/C4/D15 and B4/C0/D15
at(13,9,1), conditional on equality12 and accepted entry/cover premises.
The four normalized extensions are excluded for arbitrary finite
alphabets. E6/E26 still cover all14 parent profiles. Neither whole
third type, numerical F, alphabet separation nor complete answer is
inferred. Both extrema remain[11,12]; article/release are unchanged.

Read FINITE_INDEPENDENT_IMAGE_TRAP.md,
C4_D15_E16_E126_UNRESTRICTED_EXCLUSION.md and
SINGLETON_C_D15_GUARDED_EXCLUSION.md. The trap counts independent sets
of the exact image size, not edges. E126 has two possible independent
images. E16 O/kernels yield two/three-image traps; in their absence
mandatory isolation blocks the SC-required transition. Synchronization
is retained in every image-trap argument.

Python >=3.10, standard library only; assertions must remain enabled.

reverse pair BFS. Closed-frame certificates are checked literally and
confirmed nonsynchronizing. The E16/E126 SC/sync boundary depths(J,R)
are(6,5) and(6,4); they are not attaining F examples.
