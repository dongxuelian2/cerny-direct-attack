# Mandatory-core isolation and seventh entrance certificate

This20-file auxiliary package proves an alphabet-independent
mandatory-core lemma and applies it to the conditional thirteen-
state equality investigation. It gives no new exact F value and
is outside the unchanged109-file accepted article supplement.

Python>=3.10, standard library only, assertions enabled. Run:

    python -B check_mandatory_core_isolation.py
    python -B enumerate_b1_seventh.py
    python -B check_b1_seventh.py

Both audits and the seventh inventory reproduce byte-identically.
CHECKSUMS.txt authenticates the other19 files. No checker imports
a generator. Earlier proof notes, certificates and the sixth
inventory/audit are included as premises; the whole upstream
classification is not rerun by this package.

For strongly connected synchronizing automata, |S|>=2, m=n-|S|,
and shortest compression c(S), every x in J_m(S), the intersection
of all Sw with |w|<=m, has pair merging distance at least c(S)-m
to every distinct q. The proof reaches q within m and appends a
pair-merging word. It does not require original image reachability.
No priority claim is made for this elementary implication.

Complete binary domains at n=2,3,4 contain16,729,65,536 row pairs;
the ternary n=3 domain contains19,683 triples. Every subset of
size>=2 in every strongly connected synchronizing model is checked
by literal subset BFS and independent forward pair BFS. All290
frontier certificates and500 seeded larger-alphabet models are
checked. A transient clone preserves synchronization and actual
S reachability but destroys strong connectivity and violates the
lemma, guarding that hypothesis. Strict improvements over the
earlier depth-only singleton estimates appear in known certificates.

At n=13, |S|=9, ac(S,{3})=12, every point mandatory through four
is isolated in P7. This supersedes interpretations of the earlier
P0/P1/P2 singleton bounds as limits; those were weaker guarantees.
Their proof-bound files and valid conditional exclusions are retained.
Singleton2 at fourth or later entrances with depth>=4 strips K12
to the impossible singleton P5 cover. In particular E6/F7/G2
is now excluded for every alphabet, extending the binary exclusion;
E6/F7/G8/H2 is also excluded. E6/F2 gets another proof of its
already known all-alphabet exclusion.

The seventh E6/F7/G8 space checks seven geometries/19 labels,
77,805 subset masks and7,405 augmented exact ranks. It retains
all three additional Boolean remainders, then rejects them as
uncovered by K. This proves a common seventh only after the
clique-cover condition is applied. H2's1094 field pairs remain
as controls; active seventh admission has six geometries/18 labels,
2380 binary field pairs, still covering all365 parent sixth pairs.

No whole sixth/fifth/third/joint branch is excluded and no numerical
alphabet separation is proved. Both F(13,9,1) intervals remain[11,12].
Selected unrestricted sixth geometry drops from13/53 to12/52
because of the G2 cut; selected binary eight/40 is unchanged.
