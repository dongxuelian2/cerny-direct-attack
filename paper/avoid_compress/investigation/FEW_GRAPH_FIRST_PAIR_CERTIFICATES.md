# Complete first-pair certificates with arbitrary retained class counts

These certificates are conditional at (n,s,r,ac)=(13,9,1,12), for
strongly connected synchronizing complete automata over any finite
alphabet. They do not give a numerical F value or an alphabet separation.
The current authority and selected geometries are specified by a frozen
scope, not by mutable live-state reads during enumeration.

The premises and equality-flag induction are those of
B2_COLUMN_FIRST_PAIR_EXCLUSION.md and LOCAL_EQUALITY_FLAG.md. Each native
immediate graph domain is reconstructed by check_b1_b2_inverse_union.
All graph classes rejected there have a checked missing supplier or
proper closed set, including every labelled D transport. No assumption
is made about the number of retained classes; every retained class must
occur in the scope and in the independent checker.

In each class enumerate ALL ordered distinct feasible nine-sets S,T.
An actual extremizer has dim V1=2, with a basis of these two actual
images. Relabelling preserves H,A,B,C,D, the mandatory intersection and
each individual native field. The whole immediate graph, all exact
kernel masks, the P3 subgraph and both images are transported together.
The checker independently rebuilds every labelled pair, permutation and
representative multiplicity. The representatives need not be a minimal
orbit transversal.

For each representative the generator enumerates literal maps by
output-atom bijections; the checker independently assigns exact kernel
blocks to output states. Full sorted-row and supplier-flag hashes must
coincide. At each equality-flag node every possible next independent
image of its last basis row is explored, and all permitted Boolean
vertices in the enlarged span are retained. Every required supplier
must survive. A true actual alphabet and its actual flag therefore
remain in some branch. A proper closed set in the union of all remaining
literal arrows contradicts strong connectivity of any actual alphabet.

Full-prefix column deductions apply only from flag depth four. Their
paper proof and audits remain separately bound. Forced-word propagation
uses explicit actual words of length at most eleven; it may reject a
letter only with a checked unsafe word, and may force a letter only
through a singleton required supplier group. The independent checker
reconstructs every deletion and every complete branch using Fraction
elimination. Modular generator elimination is exact by the previous
Hadamard bound for thirteen-column characteristic nine-set rows.

Depth eleven survivors are candidates and abort a negative certificate.
Its last basis row is never mapped under a depth-twelve safety premise.
Neither incomplete prefixes nor timeouts supply an exclusion. All four
prior binary profile-cut lists are preserved when composing exclusions.
A whole joint is removed only when no remaining geometry belongs to it.

Scope-specific generators and independent audits, immutable packaging,
byte-identical isolated regeneration and all historical source checks
gate adoption. Excluding all initial subsets is stronger than excluding
only actual reachable images, so the paper's reachability requirement
has not been weakened. Counts describe structural exclusions only;
both F values at (13,9,1) retain their recorded numerical intervals.
