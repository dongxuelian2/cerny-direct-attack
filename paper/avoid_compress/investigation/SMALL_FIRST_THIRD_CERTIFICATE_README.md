# Binary B2 / four-point second-entrance certificate

This standalone auxiliary package contains the symbolic conditional proof
B2_FOUR_POINT_SECOND_EXCLUSION.md and an independent audit of its complete
third-preimage admission and finite kernel/core cases. It also preserves
the complete B1/B2 third admission, including additional same-level fibers.
The established H cover and |P1|<=4 bound are premises, with their original
notes included. This package does not reproduce the larger earlier native
certificates or establish the accepted global upper theorems by itself.

With Python 3.10+ and the standard library, run:

```sh
python check_small_first_third.py
```

The checker must report pass: 29 original B1/B2 joint records, 235 geometric
third orbits, 182 typed binary orbits, 965 binary profile pairs, and 30
orbits admitting an additional Boolean fiber. The focused exclusion checks
all 59 labelled D sets (eight orbits), reduces to two binary profiles,
enumerates 5,894 abstract R kernels and 108 core assignments, and verifies
the explicit four-step merging word or the backward-closed nonempty set.
Counts are necessary admissions and symbolic proof controls, not full row
enumeration. A negative bounded solver answer is never used.

The package authenticates its original files with CHECKSUMS.txt. Running
the checker regenerates small_first_third_audit.json byte for byte.
The original joint inventory remains intact so exclusions are explicit.
The resulting binary joint count is 28, unrestricted remains 43, and
both extrema at (13,9,1) remain in [11,12]. The |C|<=3 consequence also
uses the earlier |B|<=2 and second-entrance size bounds; its prerequisite
branch certificates are indexed separately by the repository audit.
The manuscript and its accepted 109-file supplement are unchanged.
