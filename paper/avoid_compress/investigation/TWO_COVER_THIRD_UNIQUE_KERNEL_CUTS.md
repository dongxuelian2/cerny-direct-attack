# Unique-kernel restrictions on third entrance fields

At (13,9,1), equality12, the established third inventory contains
every possible exact preA/preB/preC field for its B,C,D geometry,
including every covered Boolean companion. Its literal nine-set
family contains every actual image through depth eight. Reconstruct
its mandatory intersection J and put K={0,1,2} minus J. Only records
with |K|=2 use this note. Mandatory-core isolation makes J isolated
in P7, so K still covers P5. Synchronization and the credited
unique-immediate-pair consequence imply one global kernel pair e,
meeting K and avoiding J; every letter has rank at least12.

For an exact field, partition inputs by their memberships in its
three preimage sets and outputs by memberships in A,B,C. Any input
atom must map into its corresponding output atom. Hence the rank
is at most the sum, over atoms, of min(input size,output size).
Every pair in an input atom with singleton output is an immediate
kernel. Both quantities are literally reconstructed by the checker,
including overlapping B,C and empty atoms.

Discard a field if this rank upper bound is below12. For a proposed
global e, retain only fields whose forced immediate pairs lie in
{e}. This is deliberately a necessary overapproximation: no claim
is made that every retained field realizes exactly e or synchronizes.
Every equality automaton must lie in one retained e class, and that
class must contain suppliers preA=B, preB=C, preC=D. If no e class
has all three suppliers, the whole geometry is impossible for every
finite alphabet. Suppliers may be the same or different letters.
Covered companion fibers are retained; no common-D shortcut occurs.

For a formal binary pair, either letter's rank bound below12 or two
distinct forced kernels in their union rules out that pair. Already
removed profiles are accounted for separately by the frontier
recorder. When all currently remaining pairs of a type fail, that
binary type is removed. An arbitrary-alphabet cut always uses the
supplier test above, never failure of the binary pair table.

The finite table is an exact conditional classification, not a
thirteen-state automaton scan or a sampled-negative theorem. The
underlying unique-kernel statement is uniform and previously audited.
No result for a three-state cover is inferred. These restrictions
alone do not determine F(13,9,1), an all-parameter formula or alphabet
separation. The checker emits cuts for the intact historical inventory;
the checkpoint recorder computes only newly removed current entries.
