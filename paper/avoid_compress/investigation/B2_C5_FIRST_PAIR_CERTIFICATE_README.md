# Conditional B2-mixed C5 third3 staircase certificate

Python3.10 or later, standard library only, assertions enabled:

```
python -B enumerate_b2_c5_first_pair.py
python -B check_b2_c5_first_pair_controls.py
python -B check_b2_c5_first_pair.py
```

The inventory and both new audit reports must regenerate byte-identically.
The generator recomputes every one of12320 labelled first pairs and their
transports to64 representatives, then enumerates1002240 literal letters
and every branch of the actual-image staircase. No computation timeout
or alphabet-size bound supplies a negative. Every branch ends by depth5.

The independent checker imports only independent checking helpers. It
re-enumerates the first pairs, all field/kernel and graph transports,
assigns kernel blocks to labelled outputs directly, and checks all flag
branches using rational elimination. It also verifies the canonical D
orbit transports and complete binary profile-cut composition. Positive
flag controls and nine corrupted certificates exercise branch coverage,
domain digests, supplier sizes, next images and proper closed sets.

The earlier graph-domain certificate supplies the complete seven-class
P1 catalogue, four of whose classes remain for this staircase test.
Historical checkpoint files are frozen provenance records. This package
reproduces the three commands above; it does not claim to reproduce every
older audit listed in those checkpoints. CHECKSUMS.txt verifies every
archive member other than itself.

The scope is exactly `(n,s,r,ac)=(13,9,1,12)` with arbitrary finite
alphabets. Only b2_mixed_c5_third3 and its labelled copies are excluded.
This does not determine F(13,9,1), establish an alphabet separation or
solve Open Problem4 completely. The accepted paper remains a partial
answer. The mathematical argument is in
B2_C5_FIRST_PAIR_STAIRCASE_EXCLUSION.md.
