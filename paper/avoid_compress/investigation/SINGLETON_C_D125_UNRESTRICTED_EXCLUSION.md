# Two complete singleton-C/D125 conditional exclusions

At (13,9,1), ac(S,{3})=12, neither of the following third geometries
can occur in a strongly connected synchronizing automaton, for any
finite alphabet:

1. B={0}, C={4}, D={1,2,5}, id b1_in_c1_third5;
2. B={4}, C={0}, D={1,2,5}, id b1_out_c2_third5.

These are whole conditional third-type exclusions, not exact F values
or a numerical distinction between binary and unrestricted alphabets.

For case 1 the accepted fourth-space classification, under K={1,2}
covering P5, gives exactly E={6},{1,6},{1,2,6}, with respectively
7,14,7 labels. All further admissible covered preD fibers are precisely
A,B,C,D,E; there are no extra Boolean companions. Some letter supplies
preC=D and some supplies preD=E. The E6 paper proof excludes the first
geometry. The universal free-image proofs exclude the other two.
Thus every possible fourth extension is impossible. The three proofs
cover arbitrary alphabets and all individual fields (16,12,12), not
merely binary field pairs. All eight labels of D are covered by the
original stabilizer normalization.

Case 2 transports this complete argument by the state permutation
p=(0 4), which fixes A,D,K and all ordinary states. Removing mandatory
B and C from the original P5 cover leaves the same K={1,2} in both
cases. The old size-three cover itself is not asserted to be preserved:
only the residual cover K used by these proofs is preserved.

The literal initial families require 3,0,4 and one point of D; they
are identical after swapping B and C. The annihilator basis columns
(1 outside A,B,C,D,E), exact preimage hierarchy and target/input atoms
are conjugated by p. Rational linear identities, Boolean one-count
conditions, independence, incomparability, mandatory intersections,
and outside-K pair covers are invariant under a state permutation.
Consequently all fresh E labels and all companion fields are exactly
transported; an additional letter or fourth geometry is not omitted.
The individual third columns and 14 parent pairs of the actual second
inventory are independently checked against this transport. Both
types have eight D labels. A stabilizer element transports every
allowed D label in either normalization; no unlabelled row is assumed
to represent a fixed second letter.

At the previous frontier the first type was already excluded for
binary alphabets. The second retained nine parent pairs, after five
historical common-block exclusions. This proof removes those nine,
not all fourteen as newly excluded. For unrestricted alphabets both
whole types are newly excluded. The E6 removal already applied within
the first type and is not counted as an extra third geometry.

The composition checker independently enumerates all labelled fresh
E candidates satisfying the residual cover, incomparability, rank and
one-count initial-family conditions; it obtains exactly 28 labels in
each case. It transports all individual fields and the complete parent
third inventory, verifies source hashes for all three branch proofs,
and confirms all companion lists are retained. It also conjugates and
literally reevaluates the finite structural boundary controls. These
controls are not attaining F witnesses. No global upper or alphabet
separation is inferred from a conditional exclusion.
