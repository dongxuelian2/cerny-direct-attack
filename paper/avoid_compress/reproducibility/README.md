## Complete uniform compression proof (Theorem 6)

Read CODIMENSION_THREE_UPPER_PROOF.md first; its twelve proof notes contain the full symbolic reductions and all case analyses. The upper is for arbitrary finite alphabets, strong connectivity and synchronization, n>=6; image reachability is not needed. It implies F_bin(n,n-3,r)=F(n,n-3,r)=min(n-r,9), n>=5, 1<=r<n-3, with the separately checked lower witnesses.

## Finite exact frontier

    python -B verify_certificates.py
    python -B verify_frontier.py

The first checks all 165 triples through n=10. The second checks 290 literal binary witnesses: all 286 triples through n=12, (13,8,1), and (13,10,r), r=1,2,3. All 290 parameters are exact for both alphabet classes. The complete finite frontier ends at n=12. Other n=13 parameters are not classified by that file. The uniform codimension-three proof replaces the former binary-only covers; those completed historical computations are preserved outside the release and are unnecessary here.

The conjectured formula min(n-r,binom(n-s+2,2)) is refuted at every n>=11, s=n-3, 1<=r<=n-10, where both maxima are nine rather than ten. This remains a partial answer to Open Problem 4. No alphabet separation or all-parameter replacement formula is claimed. The determined region is m=0 (value one), 1<=m<=3 (value min(n-r,3m)), and m>=4 with n-r<=3m-1 (value n-r). Only the region m>=4, n-r>=3m remains unclassified as a whole; (13,9,1) is still in [11,12].
