05  /  THEOREM I


# 核心数学：局部检查推出全局最短性

为每个非空状态集合 S 指定一个非负整数 d(S)。你可以把它理解为：从这里开始，至少还需要多少步才能变成单点。只要下面两个条件成立，就能对任意长度、任意内容的输入串给出下界。

d({q}) = 0     且     d(S) ≤ 1 + d(S·a)

第二个条件要求对所有非空集合与所有字母成立。它允许某一步使 d 增加，但禁止一步让 d 下降超过1。如果起点的 d 值为49，而终点必须为0，那么到达终点至少需要49步。

### 完整证明

设同步词为 w=a₁…a_L，定义 S₀=Q、S_i=S_(i−1)·a_i。逐次应用局部不等式得到 d(S₀)≤1+d(S₁)≤2+d(S₂)≤…≤L+d(S_L)。终点为单点，因此 d(S_L)=0，得到 d(Q)≤L。如果另有一个长度恰为 d(Q) 的同步词，则其上界与证书下界相同，最短性成立。该证明对所有有限输入串有效。

### 为何计算可以很小

有 n 个状态时，非空子集数为2ⁿ−1；二字母实例需要检查2(2ⁿ−1)个局部不等式。n=8时仅有510项。寻找最短词可以很费力，但验证某个候选下界只需要这组确定条件。本包使用完整反向广度优先搜索产生精确势函数；这是一条实验基线。

范围  本实现显式枚举幂集，时间与内存随 n 指数增长。首轮使用 n≤10；代码输入上限为16，它不代表所有规模都有理想运行时间。

06  /  THEOREM II


# 研究切入口：压缩信息会损失多少证明能力

完整证书为每个子集保存一个数，但许多集合可能具有相似特征。设 α(S) 表示你选择保留的信息，例如集合大小，或集合大小加上是否包含0和n−1。把特征相同的集合合并成一个抽象类，就得到一个更小的表示空间。

抽象边的定义必须精确：若存在某个真实集合 S 和字母 a，满足 α(S)=x、α(S·a)=y，就建立 x→y。目标类为单点集的特征像。令 D(x) 为抽象图上到目标类的最短距离，则 d(S)=D(α(S)) 满足上一节的局部条件。证明只有一句关键理由：先沿一条抽象边走一步，再走后继到目标的最短路径，便得到 D(x)≤1+D(y)。

### 这个抽象下界已经是该特征空间的最强值

假设另一势函数 h 也只依赖 α，且满足全部局部条件。由于每条抽象边都有真实代表，h 必须在每条抽象边上满足下降至多1。沿抽象最短路径累加就得到 h(x)≤D(x)。因此，继续让模型在完全相同的特征上寻找更大势函数，无法超过 D。

### 一个重要现象：抽象图允许出现伪路径

某条抽象边可能由集合 S₁见证，下一条边却由另一个同特征集合 S₂见证。逐步合并后，抽象路径未必对应某条真实轨迹。它可能比任何真实同步路径都短。由于所有真实路径仍会映射为抽象路径，得到的下界依然有效；它只是失去了部分区分能力。

本项目因此有一个明确研究对象：认证下界与保留信息量之间的关系。你将先测量差距，再解释差距，最后将规律写成参数化定理。完整定义与证明见 docs/THEORY.md。

07  /  THEOREM III


# 可直接推进的命题：两锚点闭式

固定 n≥3。对于 Černý 实例，保留 α(S)=(k,u,v)，其中 k=|S|，u表示是否含0，v表示是否含n−1。相应抽象最短距离在全体集合上的精确值为3n−5。下面给出纸面证明；执行任务是逐项复核并完成形式化，新颖性另行审查。

| 特征条件 | 势函数 p(k,u,v) |
|---|---|
| k=1 | 0 |
| k≥2，v=0 | 3k−3 |
| k≥2，v=1，u=0 | 3k−4 |
| k≥2，v=1，u=1 | 3k−5 |

字母 a 保持 k，并把(u,v)变为(v,t)，其中t表示原集合是否含n−2。逐项代入上表，势函数下降最多1。字母 b 在v=0时不改变特征；在(u,v)=(0,1)时变成(1,0)，保持k；在(u,v)=(1,1)时变成(k−1,1,0)。最后一类转移在k≥3时使势函数下降1，在k=2时从1到0。单点情形始终为0。因此该势函数提供有效下界3n−5。

再证明它可达到。初始类(n,1,1)经b到(n−1,1,0)。对于2≤k≤n−1，抽象图存在(k,1,0)经a到(k,0,1)，再经a到(k,1,1)，最后经b到(k−1,1,0)。前两条边分别可用“含0与n−2、不含n−1”和“含n−1与n−2、不含0”的k元集合见证。重复直到k=1，路径长度为1+3(n−2)=3n−5。

边界核对  必须覆盖n=3、k=1、k=2，并只对可实现的特征类推理。3n−5是特定抽象系统的阈值；真实 C_n 的经典阈值仍为(n−1)²。[2]

源码测试已在n=3至10逐一核对每个非空子集的分段公式，并在n=3至12记录了起点数值。有限测试用于找错，普遍结论依靠上述推导。

08  /  THEOREM IV


# 更一般的障碍：旋转不变性为何只剩线性下界

进一步限制势函数不区分整体旋转：对每个集合S，都有d(S·a)=d(S)。这涵盖只看集合基数、最大循环间隙、循环间隙多重集等特征的情况。即使继续使用复杂搜索，只要势函数仍具有这种不变性，起点可认证的下界就不会超过n−1。

d(S·a) = d(S)     ⇒     d(Q) ≤ n−1

### 完整证明

考虑经典同步词 b(a^(n−1)b)^(n−2)。第一次b将全体状态变为{0,…,n−2}。若当前集合为{0,…,m−1}且m≥2，a^(n−1)把它变为{n−1,0,…,m−2}，随后b把它变为{0,…,m−2}。因此每一轮减少一个状态，最终成为单点。整个词总共使用n−1个b。

由于a不改变d，每个b又使d下降至多1，沿这条同步轨迹累加便得到d(Q)≤n−1。另一方面，d(S)=|S|−1满足全部条件：a保持基数，b每次最多减少一个状态。因此n−1确实是这个证书类的最强下界。

### 你从这个结论获得什么

它解释了一个容易误判的实验现象：循环间隙看起来比集合大小包含更多几何信息，但只要失去绝对位置相位，这些信息也可能无法改善起点认证下界。后续研究应尝试保留少量位置标记、添加历史信息，或换用更强的证书体系。每一种改变都需要重新写清假设。

可交付目标  把该障碍形式化成条件化定理，并展示三种特征满足旋转不变性。这样的结果明确说明一类方法的能力边界；它不等价于真实同步问题的普遍下界改进。

| 现象 | 先检查 | 明确动作 |
|---|---|---|

# 四周扩展：从实例走向一般方法

赛事窗口结束后，项目可沿同一核心继续推进。第一周完成当前定义、证明与语义桥梁；第二周只研究固定r=3；第三周研究缺少少量位置信息时的边界；第四周将证书接口推广到其他有限转移系统。每一步都有可独立验收的产物。

### 方向一：直接生成符号抽象图

当前代码先枚举2ⁿ个集合再合并。对于固定r个锚点，特征由基数与r个成员位组成，候选类数至多(n+1)2ʳ。可以尝试直接根据计数与位置约束生成抽象边，避开完整幂集枚举。必须证明新边集与“存在真实代表”定义完全一致，尤其不能漏边导致下界虚高。

### 方向二：证书的信息复杂度

研究指定特征层级达到某个下界比例所需的r。例如，在C_n上认证至少一半真实阈值，需要保留多少锚点？先固定锚点位置方案与证书类型，再提出量词完整的下界或上界。任何结论都应限定到所研究的表示与验证规则。

### 方向三：迁移证书原理

核心势函数定理适用于任何每步代价为1的有限转移系统。后续可研究受限规划、有限协议或带权最短路径，但每次只替换一个对象，保留检查器的信任结构。权重版本需要将“1”替换为明确的非负代价，并重新证明累加定理。

研究主线  始终追问“这份信息足够证明什么、缺少什么信息就一定证明不了什么”。这样每个新实验都有明确数学问题，而不会退化成不断扩大搜索规模。
