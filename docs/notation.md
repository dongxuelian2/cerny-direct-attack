# Notation and semantic boundaries

A complete DFA has finite states Q and original alphabet Σ. Words act on the right unless a source explicitly uses inverse processing. A reset word sends Q to one state; rt(A) is its shortest original-letter length. The target is rt(A) ≤ (n−1)² for synchronizing n-state automata.

An actual image is Qv for an original word v. The project quantity e(S) permits Ru contained in S for a larger actual image R; it does not require equality. Existential feature-quotient edges may change representative between steps, so a feature path is not automatically one concrete trajectory. Macros and permutation returns pay every original letter. In inverse subset files, listed processing order is reversed to obtain the original forward word.

Family parameters M,L,p,r and weights are source-local; do not identify them across papers without checking definitions. Lean Nat subtraction is truncated. All type definitions and hypotheses belong to a formal statement. `VERIFIED` in old Python output means checker acceptance, not Lean certification.
