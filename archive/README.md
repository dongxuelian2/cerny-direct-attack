# Preservation and publication decisions

The original research checkout is untouched as a scientific source. Its complete Git history is not rewritten; original ZIP and `openmath-final.bundle` remain in its ignored `results/openmath/` directory. Public Git starts a publication snapshot, so historical SHA identities are references, not ancestors of public main. `history.json` preserves 162 historical commit identities/dates/subjects without publishing private commit emails. `source_manifest.json` maps every committed input path/hash to its public path/hash and storage decision. Untracked composite-residual pressure scripts/data were excluded as unvalidated concurrent exploration; they remain locally available.

Retained: all committed proof and Lean sources, computational scripts, exact counterexamples, certificates, validation receipts, historical result notes, baseline manuals and provenance. The three old getting-started documents, operator prompts and blank templates moved into archive. Existing `direct_attack/RESULTS.md` and ledger are the sole historical research dumps; the clean README summarizes them.

Ignored: compiler binaries, Lean/Python caches, virtual environments, native_build, temporary files, fresh output under `.reproduction/`, and hydrated asset paths. No tracked compiler binary needed deletion. No unique scientific input was discarded. Data files larger than 1 MiB are compressed into `scientific-data.zip`, with pinned asset/member hashes in `assets.json`; both certificates and pressure inputs retain their complete content except documented path metadata redactions. Use `scripts/hydrate_data.py` to restore exact public bytes.

Privacy: historical receipts and incidental metadata contain local absolute paths. Public copies replace those paths with neutral placeholders, preserve the original source hash in the manifest, and retain dates, statuses, witnesses and theorem statements. One native compiler default now uses `g++` from PATH/CXX. Original scientific bytes and receipts remain in the local original history and frozen ZIP. Old seals remain historical seals of original bytes, not seals of this derived public tree. The new publication manifest validates public copies separately. The optional historical audit translates known original/current hash references in a scratch copy only.

Text copies use canonical LF line endings; original-byte hashes remain in the source manifest, and the formal module manifest retains historical validated source hashes separately from canonical public hashes. This normalization does not alter theorem statements.

The frozen original OpenMath ZIP SHA-256 is `1a09dadd3de876028430fa4dc7aa8353f600075d8daff9c5eae79e0a8ed7c050`. It contains private machine paths and is not uploaded. Release asset `openmath-public-payload.zip` preserves all frozen payload entries with path-only metadata redaction and canonical text line endings; it has a distinct checksum and does not pretend to have the original hash. The exact ZIP and Git bundle are preserved locally. No secret/API key/private email was detected in committed text. Bibliographic links retain attribution; [licensing scope](../docs/LICENSING.md).
